# מסכת תענית – פרק א' | משחק חזרה

משחק חזרה על פשט המשניות במסכת תענית פרק א', לתלמידי תלמוד תורה אהבת ישראל.

- 36 שאלות על שבע המשניות ו־16 מושגי יסוד. השאלות והתשובות הנכונות מועתקות מדף השאלות כלשונן.
- בכל סבב: 25 שאלות ו־7 מושגים, קודם כאלה שעוד לא הופיעו באותו מכשיר.
- כל תלמיד כותב שם ושם משפחה; הנקודות מצטברות, וטבלת עשרת הראשונים מוצגת לכולם.
- "כניסת מנהל" בתחתית מסך הפתיחה: כל התלמידים, הניקוד ופירוט של כל משחק, כולל השאלות שטעו בהן.

## מבנה
- `public/index.html` – המשחק (קובץ אחד), `public/logo.jpg` – הלוגו
- `netlify/functions/api.mjs` – השרת (Netlify Functions), הנתונים נשמרים ב־Netlify Blobs
- כשאין שרת (למשל כשפותחים את הקובץ ישירות) המשחק עובד במצב אורח, בלי שמירת ניקוד.
